# CS336 Assignment 1 · Guided Study

[Open the guided study site](https://wuhubing.github.io/cs336-assignment1-study/)

An independent, AI-assisted English study companion for Stanford CS336 Assignment 1 (Spring 2026, handout v26.0.3). The overview presents the seven-stage learning path. A collapsible, sticky contents sidebar and an “On this page” rail help you navigate. Each of the 31 lessons pairs its explanation with a worked diagram, inline figures, colour-keyed equations, and hand-picked outside reading. Sixteen lessons also include an interactive widget: UTF-8 bytes, step-by-step BPE, a toy tokenizer, embeddings, RMSNorm, SiLU gating, RoPE, attention, cross-entropy, SGD vs AdamW, the learning-rate schedule, gradient clipping, batch sampling, temperature/top-p decoding, a schematic learning-rate sweep, and a submission checklist. Lessons also show the actual unimplemented adapter stubs, two levels of conceptual hints, and local progress tracking.

**Unofficial:** This site is not affiliated with or endorsed by Stanford University or course staff. It reproduces the official `tests/adapters.py` TODO functions and clearly labels suggested scaffolds for handout tasks with no supplied stub. It provides conceptual hints, not finished assignment code or answers. Students must independently write and submit their own code, experiments, and written answers, in accordance with the [CS336 course policy](https://cs336.stanford.edu/) and official handout.
