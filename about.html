About this guide

Sources, credits & academic integrity

This is an independent, AI-assisted study companion for Stanford CS336 Assignment 1 (Spring 2026). It is not an official Stanford publication and is not affiliated with or endorsed by Stanford University or the course staff.

Use it to learn, then do the work yourself. The lessons show the official unimplemented Python adapter functions, handout-derived starter TODOs, concepts, equations, and progressive hints. The starter TODOs are clearly marked as guide suggestions. They do not include finished assignment code or answers. You must independently write the code, run experiments, analyze results, and prepare your own submission. Follow the current CS336 course policy and the official handout if either differs from this guide.

Primary source

The original Stanford CS336 Assignment 1 GitHub repository is the source of truth. This guide's content map and equation references follow its Spring 2026 v26.0.3 handout at commit a158843. Read the handout PDF for authoritative requirements, deadlines, tests, and submission instructions. This guide may contain mistakes or become outdated.
